# ToolSquid

Une boîte à outils web avec un studio de dessin et d’animation 2D.

## Ouvrir l’application

- [ToolSquid : outils du quotidien](index.html)
- [ToolSquid Studio : dessin et animation](studio.html)

Ouvre `studio.html` pour accéder directement à l’éditeur montré dans les captures. Le README est uniquement la documentation du projet ; il ne lance pas l’application.

Les pages fonctionnent localement dans un navigateur moderne, sans installation.
